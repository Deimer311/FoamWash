APÉNDICES ............................................................................................19 1 Introducción Propósito El propósito de este documento es definir los requisitos del sistema de software que permitirá a la empresa Lavados González tener una presencia en línea mediante un sitio web con portafolio de servicios. Este documento está dirigido al cliente Edilberto González, al equipo desarrollador, y a cualquier parte interesada en conocer las funcionalidades y especificaciones del sistema. Alcance El sistema a desarrollar es una plataforma web destinada a visibilizar los servicios de limpieza ofrecidos por Lavados González. Permitirá mostrar información de la empresa, un portafolio detallado, opciones de contacto y solicitud de servicios. La solución busca mejorar la imagen de la empresa en línea, atraer nuevos clientes y facilitar la gestión de los servicios ofrecidos. Descripción general El sistema será una aplicación web pública y responsiva, que permita a los clientes conocer los servicios ofrecidos por la empresa, agendar citas    y contactar al personal. A su vez, los empleados y administradores podrán gestionar las solicitudes recibidas, actualizar información y tener control sobre los servicios prestados. El sistema será  independiente  y estará alojado en un servidor accesible desde internet. No forma parte de un sistema más amplio, pero puede integrarse a futuro con plataformas de facturación electrónica o herramientas de marketing digital Perspectiva del producto El sistema es una plataforma web autónoma que operará en navegadores. No depende de otros sistemas, aunque puede integrarse a plataformas de pago o redes sociales para una mejor experiencia del usuario. Funcionalidad del producto     Visualización del portafolio de servicios.   Sección de contacto y solicitud de servicio.   Formulario de cotización rápida.   Panel de administración para gestionar contenido.   Integración con redes sociales. Características de los usuarios Tipo de usuario Cliente  Formación Variable  Habilidades Básico en navegación web Actividades Consultar información, visualizar portafolio, enviar solicitudes Tipo de usuario Empleado Formación Media Habilidades Manejo básico de tecnología Actividades Consultar solicitudes asignadas, actualizar estado de servicios Tipo de usuario Administrador Formación Media/Profesional Habilidades Gestión de contenido y web Actividades Editar portafolio, responder solicitudes, gestionar el sitio web Restricciones   El sistema debe ser responsive (adaptado a móviles).   El contenido debe estar en idioma español.   Compatible con navegadores modernos (Chrome, Firefox, Edge).   Desarrollado con tecnologías web estándar (HTML5, CSS3, JS, PHP/MySQL). Suposiciones y dependencias   El cliente proveerá el contenido visual (imágenes, descripciones).   El sistema será desplegado en un hosting con soporte para PHP y MySQL.   Se asumirá conectividad constante a internet para el uso del sistema. Evolución previsible del sistema   Incorporación de pasarela de pagos.   Módulo de agendamiento en línea.   Área privada para clientes frecuentes. Requisitos específicos Esta sección presenta los requisitos funcionales y no funcionales del sistema propuesto para Lavados González, incluyendo las interfaces del sistema, comportamiento ante errores, rendimiento esperado y características que el software debe cumplir. 3.1 Interfaces del sistema El sistema estará compuesto por varias interfaces dirigidas a los distintos tipos de usuarios: Interfaz del cliente (página web): Página de inicio con presentación de la empresa. Sección de servicios ofrecidos con detalles e imágenes. Formulario para agendar citas. Formulario de contacto y sección de comentarios. Acceso a registro/login. Perfil del usuario con historial de servicios. Interfaz del empleado (área interna): Login seguro. Visualización del calendario con citas asignadas. Opción para marcar servicios como realizados. Herramientas para contactar a clientes (correo o número telefónico). Interfaces de usuario Diseño limpio, profesional y fácil de navegar. Colores institucionales (azul, blanco y gris claro). Menú de navegación con acceso a Inicio, Portafolio, Contacto y Cotizar. Interfaces de hardware No se requiere hardware específico. Funciona en cualquier dispositivo con navegador web moderno.  Interfaces de software   Sistema operativo: independiente (funciona en cualquier entorno compatible con navegador).   Requiere integración con sistema de correo electrónico para notificaciones.   Posible futura integración con APIs de pasarela de pago. Interfaces de comunicación   Comunicación cliente-servidor vía HTTP/HTTPS.   Envío de formularios mediante POST.   Seguridad por protocolo HTTPS obligatorio.
