RF-01 ingresar al sistema como cliente 

ID

Objetivo

Pasos

Resultado Esperado

CP-001

Verificar que el cliente pueda registrarse correctamente con información válida.

1. Ingresar al portal Foam Wash.

2. Seleccionar Registrarse.

3. Diligenciar todos los campos obligatorios con información válida.

4. Presionar el botón Registrar.

El sistema registra al cliente correctamente, almacena la información en la base de datos y se recibe un mensaje "tu registro se ha compleado correctamente"

CP-002

Verificar que el sistema no permita registrar un correo electrónico ya existente.

1. Ingresar al portal Foam Wash.

2. Seleccionar Registrarse.

3. Ingresar un correo electrónico previamente registrado.

4. Completar los demás campos con información válida.

5. Presionar Registrar.

El sistema impide el registro y muestra el mensaje "Error a registar usuario"

CP-003

Verificar que el sistema valide los campos obligatorios vacíos.

1. Ingresar al portal Foam Wash.

2. Seleccionar Registrarse.

3. Dejar uno o más campos obligatorios vacíos.

4. Presionar Registrar.

El sistema no registra al cliente y muestra los mensajes de validación indicando los campos obligatorios pendientes.

CP-004

Verificar que el sistema valide el formato de los datos ingresados.

1. Ingresar al portal Foam Wash.

2. Seleccionar Registrarse.

3. Ingresar un correo con formato inválido, un teléfono con menos o más de 10 dígitos o una contraseña menor a 6 caracteres.

4. Presionar Registrar.

realiza el registro y muestra los mensajes correspondientes indicando que la información ingresada es inválida.

CP-005

Verificar el comportamiento del sistema cuando ocurre un error de conexión con el servidor durante el registro.

1. Ingresar al portal Foam Wash.

2. Seleccionar Registrarse.

3. Diligenciar correctamente todos los campos.

4. Simular una pérdida de conexión o indisponibilidad del servidor.

5. Presionar Registrar.

El sistema no registra la cuenta y muestra el mensaje "No fue posible completar el registro. Intente nuevamente más tarde." sin perder la información ingresada, si aplica.

ID

Objetivo

Pasos

Resultado Esperado

CP-006

Verificar que el cliente pueda iniciar sesión con credenciales válidas.

1. Ingresar al portal Foam Wash.

2. Seleccionar Iniciar sesión.

3. Ingresar un correo electrónico registrado.

4. Ingresar la contraseña correcta.

5. Presionar Ingresar.

El sistema valida las credenciales, inicia la sesión del cliente y redirige al panel principal mostrando el inicio

CP-007

Verificar que el cliente pueda cerrar sesión correctamente

1. Iniciar sesión en la plataforma.

2. Acceder al menú de usuario.

3. Seleccionar la opción Cerrar sesión.

El sistema finaliza la sesión del cliente, elimina la sesión activa y redirige a la pantalla de inicio de sesión o página principal.

CP-008

Verificar que la sesión expire por inactividad.

1. Iniciar sesión con un usuario válido.

2.Esperar el teimpo de inactividad 

3. Intentar realizar una acción dentro de la plataforma.

El sistema cierra automáticamente la sesión por inactividad, redirige al usuario a la pantalla de inicio de sesión y muestra un mensaje como "Su sesión ha expirado por inactividad. Inicie sesión nuevamente."

CP-009

Verificar que el sistema no permita iniciar sesión cuando existan campos obligatorios vacíos.

1. Ingresar al portal Foam Wash.

4. Presionar el botón Ingresar.

El sistema no permite el inicio de sesión y muestra los mensajes de validación indicando que los campos son obligatorios.

CP-010

Verificar que el sistema valide el formato del correo electrónico antes de iniciar sesión.

1. Ingresar al portal Foam Wash.

2. Seleccionar Iniciar sesión.

3. Escribir un correo electrónico con formato inválido (ej.: usuario@ o usuario.com).

4. Ingresar una contraseña válida.

5. Presionar el botón Ingresar

El sistema no permite el inicio de sesión y muestra un mensaje indicando que el formato del correo electrónico es inválido.

CP-011

Verificar que el sistema no permita iniciar sesión con una contraseña incorrecta.

. Ingresar al portal Foam Wash.

2. Seleccionar Iniciar sesión.

3. Ingresar un correo electrónico registrado.

4. Ingresar una contraseña incorrecta.

5. Presionar el botón Ingresar.

El sistema deniega el acceso, no inicia la sesión del cliente y muestra el mensaje "Correo o contraseña incorrectos." Permite al usuario reintentar el inicio de sesión.

CP-012

Verificar el comportamiento del sistema cuando ocurre un error de conexión con el servidor durante el inicio de sesión.

1. Ingresar al portal Foam Wash.

2. Seleccionar Iniciar sesión.

3. Ingresar un correo electrónico y contraseña válidos.

4. Simular una pérdida de conexión o indisponibilidad del servidor.

5. Presionar el botón Ingresar.

El sistema no inicia sesión y muestra el mensaje "No fue posible establecer conexión con el servidor. Intente nuevamente más tarde." sin comprometer la seguridad de la información.

3. Guardar los cambios.

2. Ir a la pantalla de inicio de sesión.

3. Ingresar el correo y la nueva contraseña.
